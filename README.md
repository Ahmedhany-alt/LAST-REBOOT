# Reboot

## About the Game
Reboot is a 2D platformer game where the player explores different levels, moves through obstacles, and fights enemies using different abilities. The game focuses on movement, combat, and interactions with the environment.

## Player Abilities
The player has several movement and combat abilities:
- **Movement:** The player can move in both directions and jump to reach higher platforms.
- **Dash:** Allows the player to move quickly over short distances.
- **Ball:** A special ability that lets the player transform into a ball.
- **Attack:** The player can attack enemies.
- **Smash:** The player can perform a powerful downward attack while jumping.

## Controls
- **Movement:** WASD or Arrow Keys
- **Jump:** Spacebar
- **Dash:** C
- **Ball:** E
- **Attack:** X
- **Smash:** Jump + Down (S or Down Arrow) + Attack (X)

## Levels
The game currently contains three complete levels. Each level provides an environment for the player to move around, use abilities, and interact with different objects and enemies.

## Enemies and Dummies
The game includes different enemies and training objects:
- **Slime:** Has complete animations.
- **Mushroom:** Has complete animations.
- **Another Enemy:** Included in the game, but its animations are not fully completed.
- **Attack Dummy:** Can attack the player and deal damage.
- **Training Dummy:** Can be attacked by the player but does not attack back.

## Interactive Objects
- **Destructible Boxes:** The player can destroy these boxes, and they drop collectible coins.
- **Breakable Edges:** These objects are included, and the player can trigger their effect, but they do not break yet.

## Current Development Status
The game has three completed levels, the player's main abilities are implemented, and most of the main gameplay elements are available. Some parts are still unfinished, including the animations of one enemy and the breaking mechanic of the edges.
